# claude-themes

## To Apply

1. Download the theme that you want to use from the themes folder in this repo
2. `mv ~/Downloads/{theme name}.json ~/.claude/themes/` e.g. mv ~/Downloads/rose-pine-main.json ~/.claude/themes/
3. Start claude code and run `/theme` and select the theme you downloaded
4. Edit theme as much as you want using the file in `~/.claude/themes/[theme name.json]`
